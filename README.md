# Самостійна робота №2 — варіант 6

Тема: сайт фірми виробника меблів. React, JSX, CSS та дані з JSON.

## Запуск

У терміналі в папці `samostiina2` виконайте:

```powershell
npm install
npm start
```

Відкрийте адресу, яку покаже термінал. Щоб зупинити сервер, натисніть `Ctrl+C`.
Потрібен Node.js 22.12+ або 24. Просте відкриття `index.html` подвійним кліком не запускає React-проєкт.

Перевірка збірки: `npm run build`. Готові файли потрапляють у `dist`.

## Що виконано

- Адаптивна сторінка на React: три колонки на широкому екрані, дві на планшеті, одна на телефоні.
- Header із меню: колір тексту й фон пунктів змінюються при наведенні.
- Основний контент і дані сторінки зберігаються у `src/data.json`.
- Блок про виробника та каталог із трьох товарів.
- Футер із контактами й посиланнями на соціальні мережі.
- Локальні SVG-ілюстрації у `public/images`.

Компанія й товари навчальні. Адреса електронної пошти демонстраційна; посилання ведуть на головні сторінки соцмереж, а не на вигадані профілі компанії.

Пояснення коду й відмінностей від методички — у [EXPLANATION.md](EXPLANATION.md).
